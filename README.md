# 감성 미니멀 웨딩 청첩장

## 실행 방법
1. 압축을 푼 뒤 `index.html`을 브라우저에서 엽니다.
2. 모바일 화면에 최적화된 세로형 원페이지입니다.
3. `style.css`와 `script.js`는 HTML과 분리되어 있습니다.
4. 사진은 `assets/` 폴더에 포함된 로컬 이미지 파일을 사용합니다.

## 실제 사용 전 수정할 항목
- `index.html`에서 신랑·신부 이름, 날짜, 예식 시간, 예식장 이름과 주소를 수정하세요.
- 계좌번호와 은행명도 실제 정보로 변경하세요.
- 지도 링크의 `query=` 값은 실제 예식장 주소나 장소명으로 변경하세요.
- 현재 사진은 제공된 디자인 시안에서 추출한 미리보기 이미지입니다. 실제 청첩장 공개 전에는 두 분의 원본 웨딩 사진으로 `assets/` 이미지 파일을 교체하는 것을 권장합니다.

## 기능
- 상단 메뉴의 섹션 이동
- 웨딩 갤러리 클릭 시 확대 팝업
- 계좌번호 복사 및 확인 팝업
- 구글 지도 검색 링크 연결
- 모바일 반응형 레이아웃

## 참고
구글 지도 링크는 예시 장소명(그랜드웨딩홀 서울)을 검색하도록 연결되어 있습니다. 실제 장소가 정해지면 링크와 표시 주소를 함께 수정해 주세요.
